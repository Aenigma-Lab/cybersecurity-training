Visual guide with minimal text.

What is Session Hijacking?

Stealing a user's session to access their account.

How It Works

  • Intercept session ID.
  • Use it to impersonate user.

Types

  • Active: Direct takeover.
  • Passive: Monitor and steal.

Prevention

  • Use HTTPS.
  • Regenerate session IDs.
  • Monitor logs.

Examples

  • testphp.vulnweb.com: Vulnerable to session attacks.
  • Instagram: Target of session ID theft.
