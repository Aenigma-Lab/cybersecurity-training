> A comprehensive cybersecurity awareness training program to educate citizens about prevalent cyber threats, fraud schemes, and protective measures.

## 📋 Overview

This training program provides interactive educational content covering various cyber threats and fraud schemes that citizens may encounter in their daily digital lives. Each module includes practical demonstrations, prevention strategies, and real-world scenarios to enhance understanding of cybersecurity concepts.

**Purpose:** To empower individuals with the knowledge and skills needed to identify, prevent, and respond to cyber threats effectively.

## 🎯 Objectives

- **Raise Awareness:** Educate citizens about common cyber threats and fraud schemes
- **Provide Practical Skills:** Teach detection and prevention techniques
- **Promote Safe Digital Practices:** Encourage responsible use of technology
- **Build Cyber Resilience:** Help individuals protect their digital assets and personal information

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection for loading external resources
- Basic understanding of digital devices

### Installation

1. Clone or download this repository:
   
```
bash
   git clone https://github.com/Aenigma-Lab/cybersecurity-training.git
   
```

2. Navigate to the project directory:
   
```
bash
   cd cybersecurity-training
   
```

3. Open any HTML file in your web browser to start learning:
   
```
bash
   # For example, open the introduction page
   open "0_intro and disclamer/index.html"
   
```

### Running the Training

Simply open the HTML files in a web browser. The training modules can be accessed in any order, though they are numbered for a structured learning path.

## 🛡️ Key Security Tips Covered

- Never share OTP, PIN, or passwords with anyone
- Verify URLs before clicking (look for HTTPS and correct domain)
- Enable two-factor authentication (2FA) on all accounts
- Use strong, unique passwords for different accounts
- Be cautious of unsolicited calls and messages
- Keep your devices and software updated
- Report suspicious activities to relevant authorities
